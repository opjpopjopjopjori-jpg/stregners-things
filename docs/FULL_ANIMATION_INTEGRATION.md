# Full Animation Story Integration

Every chapter (CH01-CH05) + every role (Seer, Guardian, Gifted, Scout) + every emotional state (neutral, combat, recovery, defense, victory) produces a unique animation key.

Formula: animation.story.CH{01-05}.{role_id}.{emotional_state}

This enables AI to generate complete animated stories where each chapter event triggers the correct animation sequence for the active character.
