# Character-Specific Enhanced Animation Profiles

Deepest animation design per role, using texture islands and emotional states:

- Seer: hive_sense, observation, power focus/recovery (eye glint, hair motion, clothing calm/intense)
- Guardian: defensive guard, melee combat, brace, frontline posture (jacket/clothing dynamic, hair combat)
- Gifted: shield, push, rescue, focus/recovery (clothing active, emotional intensity)
- Scout: lookout, signal active, route marked, anchor (hair motion, clothing alert)

Every profile uses enhanced texture-compatible islands and emotional mapping.
