# AI Mod Integration Instructions

When integrating with ANY new mod (e.g., Ice and Fire with dragons, new biomes, new structures), the AI MUST generate:

1. NEW DIALOGUE about new biomes (specific facts)
2. NEW DIALOGUE observing new creature behavior (e.g., breathes fire, moves at night)
3. NEW INTERACTION per role (Guardian = defend, Seer = observe, Gifted = protect, Scout = signal)
4. NEW STORY ELEMENT in one of the 5 chapters referencing discovered features
5. NEW OBSERVATION with exact reason (not generic warning) referencing creature behavior
6. NEW BIOME FACT mentioned by character with name and accurate description
7. ZERO generic warnings — every line must reference specific discovered elements

The AI must read the discovered feature list from ProfessionalUniversalDiscovery and include all elements professionally.
