# Intelligent Character Dialogue System

Characters observe, explain, discuss, and decide together:

- Seer observes threat/time and explains reason (numbers, darkness, powerful creature, nearby shelter)
- Guardian asks/asks for clarification
- Gifted responds with ability readiness
- Scout responds with route/structure information
- All dialogue references actual world state (night, zombie groups, dragons, caves, structures from vanilla or mods)

No generic warnings. Every line references a specific observation and reason.
