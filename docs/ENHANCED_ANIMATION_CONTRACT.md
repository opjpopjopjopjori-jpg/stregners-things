# Enhanced Animation System — 10x Stronger

This system extends the base GeckoLib animation framework with:
- Enhanced body, face, and secondary-motion controllers
- Role-specific combat, interaction, emotional, and defensive poses
- Dynamic emotional state mapping (recovery, exhaustion, retreat, guard)
- Enhanced animation controller (`EnhancedCompanionAnimationController`)
- Enhanced state mapper (`EnhancedAnimationStateMapper`)
- Stronger contract for AI-generated animation sequences linked to story chapters

Every animation is non-authoritative; it consumes server-validated entity state only.
