# Professional Character Intelligence Engine

Each of the 4 roles has unique cognitive patterns:

- Seer: Analysis + Observation + Prediction + Hive Sense
- Guardian: Defense + Tactical Assessment + Group Protection + Brace
- Gifted: Magical Awareness + Boundary Assessment + Emotional Sensing + Shield/Push
- Scout: Navigation + Pattern Recognition + Route Memory + Signal/Anchor

Every role evaluates events differently, produces role-specific recommendations,
and contributes uniquely to team decision-making.
