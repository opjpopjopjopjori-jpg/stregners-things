# Critical Event Dialogue Framework

Maps 8 critical events to intense professional dialogue patterns + existing sound cues:

- combat_peak -> hive/focus.ogg
- retreat_urgent -> guardian_retreat.ogg
- shield_break -> gifted_shield.ogg
- night_fall -> seer_signal.ogg
- dragon_fire -> hive/release.ogg
- victory_final -> ui/safe_mode.ogg
- rescue_emergency -> gifted_rescue.ogg
- blizzard_critical -> scout_lookout.ogg

Uses only existing .ogg assets in the repository. No licensed recordings required.
Every dialogue is original, professional, and designed for critical emotional impact.
