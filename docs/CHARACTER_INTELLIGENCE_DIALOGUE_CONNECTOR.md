# Character Intelligence Dialogue Connector

Every dialogue line is enhanced with the speaker's cognitive profile:

- Seer: "[Analysis] ... Pattern: observation + prediction required."
- Guardian: "[Defense] ... Tactical priority: protect group, assess threat."
- Gifted: "[Protection] ... Boundary assessment: shield readiness conditional."
- Scout: "[Navigation] ... Route memory: signal placement strategic."

This ensures dialogue is never generic — every line reflects the speaker's professional intelligence profile.
