# Ambient Sound Signature Example

EXAMPLE: storm_dark.ogg
EVENT: blizzard_critical (Chapter: CH03)
DESCRIPTION: Dark storm atmosphere — thunder rolling, rain striking stone, wind howling through empty structures.
USAGE: DialogueService triggers this sound when CriticalEventDialogueFramework detects the critical event.
NOTE: User must place storm_dark.ogg in src/main/resources/assets/riftcompanions/sounds/voices/
FRAMEWORK READY: DialogueService plays it automatically when event triggers.
